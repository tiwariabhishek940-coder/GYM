# GYM

Collection of gym websites.

## Structure

```
GYM/
├── sites/
│   ├── _template/        # starter for every new site
│   └── <gym-name>/       # one folder per gym website
├── docs/
│   └── ADDING_A_SITE.md  # how to add a new site
└── README.md
```
