# Adding a new gym website

1. Copy the template: `cp -r sites/_template sites/<gym-name>` (lowercase, hyphens, e.g. `sites/fitzone-bhopal`)
2. Build the site inside that folder.
3. Fill in the site's own `README.md` (client, location, stack, live URL, status).
4. Add a row to the table in the root `README.md`.
5. Commit and push.
